Lógica de falla del sistema

Si cualquiera de las dos cámaras necesarias para el análisis deja de transmitir durante más de 5 segundos, el sistema muestra SISTEMA FUERA DE SERVICIO y suspende la autorización de nuevos ingresos.

El sistema no mostrará "Ingreso permitido" cuando no disponga de la información necesaria para tomar una decisión.
