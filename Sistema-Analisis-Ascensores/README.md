# Sistema de Análisis y Detección de Sobrecarga en Ascensores

Estructura inicial del repositorio para el proyecto universitario.

## Organización propuesta

- `frontend/`: sitio web y sus pantallas/interfaz.
- `backend/`: lógica del sistema y servicios del sitio web.
- `microservicio-vision/`: componente previsto para detección, tracking y procesamiento de las cámaras.
- `database/`: scripts y organización prevista para datos.
- `docs/`: documentación, requerimientos, arquitectura, diagramas y Scrum.

Esta versión contiene únicamente la organización inicial del proyecto; no incluye código funcional.
